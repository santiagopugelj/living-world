# CHANGELOG - Living World

## v0.12 - 2026-08-08

- Added a visual progress bar for tree gathering
- Improved feedback during resource gathering

- Changed tree gathering from instant interaction to a timed action
- Added mouse-based tree gathering
- Gathering is cancelled when the player moves too far away

- Added the first player resource interaction

- Added a basic wood counter

- NPCs now choose nearby trees instead of random trees

## v0.8 - 2026-08-07

- Stuck NPCs automatically choose a new destination

- Added subtle random size variation to world objects

- Added collision detection for NPCs
